### Featured work

**[Tbx1-depleted-Tbx1cre-lineage](https://github.com/drgideonobeng/Tbx1-depleted-Tbx1cre-lineage)** —
Four-phase Nextflow pipeline characterizing cell-autonomous
Tbx1 loss in cardiopharyngeal progenitors. scVI integration
(batch correction with preserved KO phenotype), pseudobulk
DESeq2, GO enrichment. Identifies neural crest loss,
cardiac maturation impairment, and KO-specific neuronal
fate adoption at single-cell resolution.

**[Mesp1cre-lineage-developmental-atlas](https://github.com/drgideonobeng/Mesp1cre-lineage-developmental-atlas)** —
Phased Nextflow pipeline for Mesp1 cardiopharyngeal
lineage analysis across E8.0→E10.5. fastMNN integration
into a developmental atlas with documented artifact
recovery. Explore it live:
**[mesp1 Atlas Explorer](https://drgideonobeng.shinyapps.io/mesp1_explorer)** —
deployed R Shiny app, ~22k cells across 15 cell types.

**[Mouse-embryonic-brain-multiome-analysis](https://github.com/drgideonobeng/Mouse-embryonic-brain-multiome-analysis)** —
Joint scRNA-seq + scATAC-seq integration (Seurat v5 WNN +
Signac) resolving 13 cell types, with ATAC coverage tracks
and motif enrichment linking chromatin state to lineage
identity.

**[Kdr-depleted-Mef2cAHFcre-lineage-seurat](https://github.com/drgideonobeng/Kdr-depleted-Mef2cAHFcre-lineage-seurat)** —
Conditional-knockout lineage analysis with validated cloud
execution on AWS Batch + S3 via the Nextflow executor.
