## Gideon Obeng

Computational biologist and cell biologist building 
reproducible single-cell genomics pipelines. PhD in 
Molecular Pathobiology (Mie University); Postdoctoral 
Associate at Rutgers NJMS.

### Featured work

**[tbx1](https://github.com/drgideonobeng/tbx1)** — 
Four-phase Nextflow pipeline characterizing cell-autonomous 
Tbx1 loss in cardiopharyngeal progenitors. scVI integration 
(batch correction with preserved KO phenotype), pseudobulk 
DESeq2, GO enrichment. Identifies neural crest loss, 
cardiac maturation impairment, and KO-specific neuronal 
fate adoption at single-cell resolution.

**[mesp1](https://github.com/drgideonobeng/mesp1)** — 
Phased Nextflow pipeline for Mesp1 cardiopharyngeal 
lineage analysis across E8.0→E10.5. fastMNN integration 
into a developmental atlas with documented artifact 
recovery.
